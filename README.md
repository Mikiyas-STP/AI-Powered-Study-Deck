# AI-Powered Study Deck (PAPR Stack)

A production-ready full-stack application that uses AI to transform raw notes into study-ready flashcards using a Spaced Repetition System (SRS).

## 🚀 Tech Stack
- **Backend:** FastAPI (Python 3.11), SQLAlchemy 2.0, PostgreSQL, Alembic.
- **Frontend:** React, Vite, Tailwind CSS, Axios.
- **AI/ML:** OpenAI/Groq API (Structured JSON Outputs).
- **DevOps:** Docker, Pytest (Integration Testing), Pydantic (Data Validation).

## 🏗️ Architecture
The project follows a modular, domain-driven design:
- **Stateless Auth:** JWT-based authentication with Bcrypt password hashing.
- **Database:** Relational schema with UUIDs for security and Spaced Repetition fields.
- **Dependency Injection:** FastAPI dependencies manage DB sessions and Auth state.
- **Testing:** 100% pass rate on core business logic via Pytest.
